<h1 align="center">0xHNZ/dotfiles</h1>

This is where I keep all of my dotfiles.

## Software I Use

- **Operating System:** [Ubuntu](https://ubuntu.com/)
- **Desktop Environment:** [GNOME](https://www.gnome.org/)
- **Window Tiling:** [Tiling Shell](https://github.com/domferr/tilingshell)
- **Terminal:** [Ghostty](https://ghostty.org/)
- **Shell:** [Zsh](https://www.zsh.org/)
- **Prompt:** [Starship](https://github.com/starship/starship)
- **Editor:** [VS Code](https://code.visualstudio.com/)
- **Notes:** [Obsidian](https://obsidian.md/)
- **GTK Theme:** Graphite-Dark
- **Icons:** YAMIS
- **Terminal Font:** DM Mono
- **System Extensions:** GNOME Extensions
- **Appearance:** Dark Mode, Blur My Shell, Rounded Window Corners


## Where is everything?

This repository is still a work in progress. Dotfiles, configuration files, and scripts will be added as the setup evolves.
